# Contributing to Agri Nirvana

Thank you for your interest in contributing to **Agri Nirvana**! We welcome contributions from developers, agronomists, data scientists, and designers worldwide to improve smallholder agricultural productivity.

---

## 🛠️ How to Get Started

1. **Fork the Repository**: Click the **Fork** button at the top right of the GitHub page.
2. **Clone your Fork**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/agri-nirvana.git
   cd agri-nirvana
   ```
3. **Install Dependencies**:
   ```bash
   npm install
   ```
4. **Run Development Server**:
   ```bash
   npm run dev
   ```

---

## 🧪 Testing Before Submitting

Always test your changes by running the production build locally:

```bash
npm run build
```

Ensure there are **0 linting or compilation errors** before creating a Pull Request.

---

## 📋 Pull Request Guidelines

- Create a descriptive branch name (e.g., `feature/3d-soil-moisture` or `fix/mandi-feed`).
- Keep Pull Requests focused on a single feature or bug fix.
- Follow existing React & Three.js component code style.
