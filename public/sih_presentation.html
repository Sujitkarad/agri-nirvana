Problem Context & Innovation Overview

The Ground Reality (Maharashtra Farmers)

  • Delayed Manual Scouting: Disease detection happens only after 30-40% leaf defoliation occurs.
  • Indiscriminate Over-Spraying: Blanket chemical application increases input cost by 35% and pollutes soil.
  • Commercial Cloud Reliance: Paid APIs fail in low-connectivity rural belts (Vidarbha / Marathwada).

The Agri Nirvana Solution

  • 100% Self-Hosted ML Pipeline: 0 third-party API dependencies; runs locally on PyTorch CPU/GPU.
  • Stage A + Stage B Neural Architecture: Filters non-crop photos before 38-class PlantVillage disease classification.
  • Targeted Spot-Spray Telemetry: Generates KML drone flight waypoints to spray *only* infected crop patches.
SLIDE 03 / 06

2-Stage Machine Learning Pipeline

01

Stage A: Plant Validation Gate

MobileNetV2 (ImageNet-1K) mapped against ~75 plant/vegetation class categories. Instantly rejects non-plant images (cars, faces, equipment).

Latency: ~50-80ms (CPU)
02

Stage B: Disease Classifier

PlantVillage MobileNetV2 fine-tuned on 38 pathogen classes across 14 crop species. Outputs exact disease class and neural confidence score.

Latency: ~50-100ms (CPU)
03

HSV Damage Segmentation

OpenCV color space thresholding segments healthy green foliage vs. necrotic brown/yellow spot pixels to calculate exact foliage damage %.

Accuracy: Quantitative Area %

TIER 1: BIOLOGICAL

Targeted Fungicides

Specific active ingredient dosage (e.g. Azoxystrobin + Difenoconazole @ 1ml/L) with strict Pre-Harvest Intervals (PHI).
