# Security Policy

## Supported Versions

We actively issue security patches and updates for the following versions of **Agri Nirvana**:

| Version | Supported          |
| ------- | ------------------ |
| 3.x.x   | :white_check_mark: |
| < 3.0.0 | :x:                |

## Reporting a Vulnerability

The Agri Nirvana team takes security vulnerabilities seriously.

If you discover a potential security issue (e.g., API key leaks, client-side XSS, remote payload injection), please **do not open a public issue**.

Instead, please send an email directly to **security@agrinirvana.org** or report via GitHub Security Advisories.

We aim to respond to all security reports within **48 hours** and provide a patch release within **7 business days**.
